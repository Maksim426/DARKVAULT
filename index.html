Android (.APK) · Широкий режим

  • Скачайте DarkVault.apk на телефон Android и разрешите установку из неизвестных источников.
  • Широкий горизонтальный формат (Авто, 19.5:9, 20:9, 21:9) заполняет весь экран телефона без чёрных полос.
  • Мультитач-стики, кнопки рывка, бомбы и реликвии подстраиваются под соотношение сторон автоматически.

Windows (.EXE), Linux & Редактор кода

  • Workflow .github/workflows/build-installers.yml собирает DarkVault.exe, DarkVault (Linux) и DarkVault.apk.
  • Встроенный Редактор кода для ПК: подсветка Python, Undo/Redo, поиск Ctrl+F, проверка синтаксиса и ИИ-агент.
  • Атомарные сохранения (.tmp + os.replace) и стабильный выход для Linux (Arch / Hyprland).

Локальная сборка

  • Android: ./Android installer/BUILD_ANDROID_APK.sh
  • Linux: ./Linux installer/BUILD_LINUX.sh
  • Windows: Windows installer\BUILD_WINDOWS.bat
