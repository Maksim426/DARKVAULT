# Android Installer (.APK) · Подземелье Тьмы (DarkVault)

## Скачать на телефон БЕЗ ПК (прямая установка `.apk`)

1. Откройте этот репозиторий в браузере прямо на телефоне Android и перейдите в раздел **[Releases (Последний релиз)](https://github.com/Maksim426/DARKVAULT/releases/latest)**  
   или нажмите прямую ссылку: **[⬇️ Скачать DarkVault.apk](https://github.com/Maksim426/DARKVAULT/releases/latest/download/DarkVault.apk)**.
2. Нажмите на **`DarkVault.apk`** — браузер сразу скачает готовый установочный файл (ничего распаковывать не нужно, ПК не нужен).
3. Откройте скачанный `.apk` и при необходимости разрешите установку из браузера («Установка из неизвестных источников»).

> **Если в Releases ещё нет сборки:** прямо с телефона откройте вкладку **Actions → Build Windows, Linux & Android Installers → Run workflow** и нажмите зелёную кнопку **Run workflow**. Облако GitHub само соберёт `.apk` (~10–15 минут) и автоматически опубликует `DarkVault.apk` в **Releases**.

## Альтернатива без ПК и без ожидания сборки — через **Pydroid 3**

Если хочется запустить игру на телефоне прямо сейчас из исходников без ПК:
1. В мобильном браузере на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив на телефон.
2. Установите приложение **Pydroid 3** из Google Play.
3. В **Pydroid 3** откройте меню **Pip** и установите библиотеки `pygame` и `pillow`.
4. Откройте `GAME/main.py` и нажмите **▶ (Запуск)** — при необходимости включите сенсорное управление в **Настройки → Сенсорное управление → ВКЛ**.

## Сенсорное управление (встроено в игру)

При запуске на Android (или при включении опции **«Сенсорное управление → ВКЛ»** в Настройках) игра автоматически включает полупрозрачный монохромный интерфейс управления для альбомного режима:
- **Левый виртуальный стик** (динамический под большим пальцем) — плавное движение на 360°.
- **Правый виртуальный стик** — прицеливание и стрельба в 4 стороны с подсветкой направления.
- **Кнопка «Рывок»** (с индикатором перезарядки) — теневой телепорт с неуязвимостью.
- **Кнопка «Бомба»** (со счётчиком бомб) — установка бомбы.
- **Кнопка «Реликвия»** (со шкалой заряда) — активация активного артефакта.
- **Кнопка паузы `||`** в правом верхнем углу и поддержка системной кнопки **Назад** на Android.
- **Ячейки инвентаря** — переключение артефактов нажатием пальца прямо по слотам.

## Для разработчиков — локальная сборка `.apk` на ПК (без WSL2) через Docker

Если вы хотите запустить сборку на своем ПК под управлением Windows с помощью Docker:
1. Установите и запустите [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/).
2. Перейдите в папку `Android installer`.
3. Запустите файл **`build_apk_windows_docker.bat`** (двойным кликом).
4. Скрипт автоматически подготовит ассеты и запустит сборку в официальном контейнере Buildozer.
5. Готовый файл появится в папке **`dist/android/DarkVault.apk`** — после этого вы сможете скинуть его сюда!

## Для разработчиков — сборка `.apk` на Linux / WSL2

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip python3-venv autoconf libtool pkg-config zlib1g-dev libncurses-dev cmake libffi-dev libssl-dev ccache

cd "Android installer"
chmod +x BUILD_ANDROID_APK.sh
./BUILD_ANDROID_APK.sh
```
Готовый файл появится в `../dist/android/DarkVault.apk`.
